# java-lotto-precourse

## 구현할 기능 목록

### 입력

- [ ]  구입 금액 입력
- [ ]  당첨 번호 입력
- [ ]  보너스 번호 입력

### 출력

- [ ]  구매 개수 출력
- [ ]  구매한 로또 리스트 출력
- [ ]  구매한 로또 리스트 중 몇 개 일치했는지 출력
- [ ]  수익률 출력

### 기능

- [ ]  구입 금액에 해당하는 만큼 로또 발행하기
- [ ]  1개의 로또를 발행할 때 중복되지 않는 6개의 숫자 뽑기
- [ ]  번호 일치 여부에 따라 등수 매기기
- [ ]  등수에 따라 당첨 금액 부여하기

## 예외 케이스

### 구입 금액 입력

- [x]  1,000원 단위 입력 검증 (나누어 떨어지지 않으면 예외 처리)

### 당첨 번호 입력

- [x]  번호가 쉼표 기준으로 구분되는지 검증
- [x]  번호가 6개인지 검증
- [x]  중복되는 번호가 있는지 검증

### 보너스 번호 입력

- [ ]  번호가 아니라 다른 형식은 아닌지 검증
- [ ]  당첨 번호 6개와 중복되지 않는지 검증

### 잘못된 값 입력

- [ ]  예외 발생 및 그 부분부터 입력 다시 받기
