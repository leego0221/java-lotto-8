# java-lotto-precourse

## 구현할 기능 목록

### 입력

- [x]  구입 금액 입력
- [x]  당첨 번호 입력
- [x]  보너스 번호 입력

### 출력

- [x]  구매 개수 출력
- [x]  구매한 로또 리스트 출력
- [x]  구매한 로또 리스트 중 몇 개 일치했는지 출력
- [ ]  수익률 출력

### 기능

- [x]  구입 금액에 해당하는 만큼 로또 발행하기
- [x]  1개의 로또를 발행할 때 중복되지 않는 6개의 숫자 뽑기
- [x]  번호 일치 여부에 따라 등수 매기기
- [ ]  등수에 따라 당첨 금액 부여하기

## 예외 케이스

### 구입 금액 입력

- [x]  공백 계열은 아닌지 검증
- [x]  Integer 타입인지 검증
- [x]  1,000원 미만인지 검증
- [x]  1,000원 단위인지 검증

### 당첨 번호 입력

- [x]  공백 계열은 아닌지 검증
- [x]  번호가 쉼표 기준으로 구분되는지 검증
- [x]  쉼표 구분 이후 올바르게 번호가 추출되었는지 검증
    - 공백 계열은 아닌지 검증
    - Integer 타입인지 검증
    - 1에서 45 사이에 있는지 검증
- [x]  쉼표 구분 이후 번호가 6개인지 검증
- [x]  쉼표 구분 이후 중복되는 번호가 있는지 검증

### 보너스 번호 입력

- [x]  공백 계열은 아닌지 검증
- [x]  Integer 타입인지 검증
- [x]  1에서 45 사이에 있는지 검증
- [x]  당첨 번호 6개와 중복되지 않는지 검증

### 잘못된 값 입력

- [ ]  예외 발생 및 그 부분부터 입력 다시 받기
